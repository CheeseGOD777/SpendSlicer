Setup Required

To use this dashboard, configure your AWS credentials:

1
Configure AWS CLI credentials: aws configure
2
Required IAM permissions: ce:GetCostAndUsage, ce:GetCostForecast, sts:GetCallerIdentity
3
For "By Resource Name" view — activate the Name tag: AWS Billing Console → Cost Allocation Tags → Activate "Name" as a user-defined cost allocation tag. Takes ~24h to populate.
4
Select your profile above to connect to the right AWS account.
