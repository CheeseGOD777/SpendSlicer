The 8 sub-projects that solve the AWS billing problem

Self-hosted, user-owned credentials, zero server-side custody. Click the cards you'd include in v1 MVP (multi-select). My recommendation: 1, 2, 3, 6, 7, 8.

1

Core Engine & Data Model MVP

Foundation. Kill the 1,091-line monolith. Modular layers: AWS client wrapper, cost processor, resource enumerator, audit engine, export handlers, web server. Multi-profile + multi-region + multi-account (AWS Organizations / assumed role). Local SQLite for cache + history. Async job runner so scans don't block the UI.

2

Cost Visibility & Attribution MVP

Our existing strength, extended. Cost Explorer by service/tag/account/region, instance-level attribution (EC2/EBS/RDS/ELB/EIP — we already do this better than the ref tool). Extend to S3, Lambda, DynamoDB, NAT, CloudFront, data transfer. 6-month trend charts. Forecast. Tag-value filtering.

3

FinOps Audit Engine MVP

Biggest gap vs ref tool. Untagged resources (all services/regions), idle/unused (stopped EC2, unattached EBS, unused EIPs, orphaned snapshots, old AMIs, idle RDS, idle ELBs), budget breach detection, tagging policy violations. Per-region sweeps with parallel fetches.

4

Optimization & Recommendations PRO

The "why pay" tier someday. Rightsizing (underutilized EC2/RDS from CloudWatch metrics), RI/Savings Plan recommendations & coverage, Graviton migration candidates, gp2→gp3, S3 storage class optimization, CloudWatch Logs retention, NAT Gateway consolidation, Compute Optimizer + Trusted Advisor integration.

5

Anomaly Detection & Alerting PRO

Cost spike detection (±20% vs trailing 7-day baseline), forecasted-budget-overrun alerts, per-service anomaly detection, alert routing via webhook/Slack/email. Needs time-series store + scheduler, nontrivial complexity — better as v2.

6

Reporting & Distribution MVP

PDF / CSV / JSON export (more polish than ref tool), scheduled reports (cron-style, runs locally or in user's Lambda), Slack & Teams integration, S3 archival, SES/SMTP email delivery. Shareable, printable, auditable outputs.

7

Web UI & UX MVP

Modern SPA dashboard. Views: Cost Explorer, Trends, Audit, Resources drill-down, Recommendations, Settings. Multi-account rollup. Profile/region switcher. Dark mode. Interactive charts with drill-down. Design-led, not generic AI aesthetic.

8

Distribution, Packaging & Install MVP

pipx install aws-cost-ultra, Docker image, optional PyInstaller binary. First-run wizard (auto-detect AWS profiles, pick region scope, seed SQLite). Auto-update check. Opt-in anonymized telemetry. This is what makes it feel like a product, not a script.

Recommended MVP cut: 1, 2, 3, 6, 7, 8. Skip 4 (optimization) and 5 (anomaly) for v1 — they're complex, need historical data, and are natural "Pro" tier features once the free tool gets traction. v1 already beats the reference tool substantially while staying shippable.
